### Вариант 2: Ручное исправление

Если автоматический скрипт не работает:

#### Шаг 1: Переместите проект

```powershell
# PowerShell от имени администратора
New-Item -ItemType Directory -Path "C:\Projects" -Force
Move-Item -Path "C:\Windows\system32\PS_AI_P" -Destination "C:\Projects\PS_AI_P" -Force
cd C:\Projects\PS_AI_P
```

#### Шаг 2: Очистите старые зависимости

```powershell
Remove-Item -Recurse -Force node_modules -ErrorAction SilentlyContinue
Remove-Item -Force package-lock.json -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force backend\venv -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force backend\node_modules -ErrorAction SilentlyContinue
```

#### Шаг 3: Создайте виртуальное окружение

```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Если не работает, используйте cmd:
```cmd
cmd
cd backend
venv\Scripts\activate
```

#### Шаг 4: Установите зависимости

```powershell
# В venv (должно быть (venv) в начале строки)
python -m pip install --upgrade pip
pip install -r requirements.txt

cd ..
npm install
```

#### Шаг 5: Соберите frontend

```powershell
npm run build
```

#### Шаг 6: Запустите backend

```powershell
cd backend
.\venv\Scripts\Activate.ps1
python main.py
```

#### Шаг 7: Откройте браузер

http://localhost:7860

## 🐛 Если возникают ошибки

### Ошибка: "pywin32==306 not found"
**Решение:** Уже исправлено в requirements.txt

### Ошибка: "npm.ps1 cannot be loaded"
**Решение:**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Ошибка: "venv\Scripts\Activate.ps1 не работает"
**Решение:** Используйте cmd вместо PowerShell:
```cmd
cmd
cd backend
venv\Scripts\activate
```

### Ошибка: "404 Not Found" на http://localhost:7860
**Решение:** Frontend не собран. Выполните:
```powershell
npm run build
```
