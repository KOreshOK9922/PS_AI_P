## 🔍 Диагностика

Если что-то не работает:

### Проверьте что бэкенд запущен

```powershell
# В PowerShell выполните:
curl http://localhost:7860/health
```

**Ожидаемый ответ:**
```json
{"status":"ok","plant_simulation":false,"connection_method":"demo"}
```

### Проверьте логи

В консоли где запущен `python main.py` должны быть логи:
```
[HH:MM:SS] [INFO] [SYSTEM] PS AI Agent Backend v2.0 запущен
[HH:MM:SS] [INFO] [SYSTEM] API: http://localhost:7860
```

### Проверьте порты

```powershell
# Проверьте что порт 7860 свободен
netstat -ano | findstr :7860
```

Если порт занят, убейте процесс:
```powershell
# Найдите PID
netstat -ano | findstr :7860
# Убейте процесс (замените PID)
taskkill /F /PID <PID>
```

## 🐛 Частые проблемы

### Проблема: "localhost не запустился"

**Решение:**
1. Убедитесь что `python main.py` запущен и нет ошибок
2. Проверьте что порт 7860 не занят
3. Попробуйте другой браузер
4. Проверьте firewall

### Проблема: "npm run build failed"

**Решение:**
1. Удалите `node_modules` и `package-lock.json`
2. Выполните `npm install` заново
3. Выполните `npm run build`

### Проблема: "ModuleNotFoundError"

**Решение:**
```powershell
cd backend
pip install -r requirements.txt
```

## 📞 Поддержка

Если проблемы не решены:

1. Проверьте логи в консоли где запущен `python main.py`
2. Проверьте файл `agent_log.txt` (создается при работе)
3. Убедитесь что все зависимости установлены
4. Перезапустите систему
