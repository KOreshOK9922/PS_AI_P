# 🤖 Multi-Agent Code Generation System

## 🎯 Обзор

Мультиагентная система (рой агентов) для автономной генерации высококачественного программного кода на базе локальных LLM.

**7 специализированных агентов работают вместе для создания кода промышленного качества!**

## 🏗️ Архитектура

### 7 специализированных агентов:

1. **🎯 Orchestrator** — управление жизненным циклом, маршрутизация
2. **📊 Product Analyst** — формализация требований, User Stories
3. **🏛️ System Architect** — проектирование архитектуры, выбор стека
4. **💻 Lead Engineer** — реализация кода по спецификациям
5. **🧪 QA Engineer** — тестирование (TDD), валидация
6. **🔍 Code Reviewer** — ревью, security audit
7. **🚀 DevOps Engineer** — упаковка, CI/CD, Docker

### Workflow:

```
Требование → Оркестратор → Аналитик → Архитектор → Разработчик → QA → Ревьюер → DevOps → Готово
                              ↑_________________________________________|
                                        (цикл обратной связи)
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Python backend
cd backend
pip install -r requirements.txt

# Node.js frontend
cd ..
npm install
```

### 2. Настройка Ollama

```bash
# Установите Ollama: https://ollama.com
ollama pull qwen2.5-coder:7b
# Или более мощную модель:
ollama pull qwen2.5-coder:14b
```

### 3. Запуск системы

```bash
# Сборка frontend
npm run build

# Запуск backend
cd backend
python main.py

# Откройте http://localhost:8000
```

## 📋 Использование

### Веб-интерфейс

1. Откройте http://localhost:8000
2. Введите требование (например: "Создай REST API для управления пользователями")
3. Нажмите "▶ Запустить"
4. Наблюдайте за работой агентов в реальном времени
5. Просматривайте артефакты: требования, архитектуру, код, тесты

### API

```bash
# Запуск задачи
POST /api/run
{
  "requirement": "Создай REST API для управления пользователями",
  "max_iterations": 3
}

# Статус задачи
GET /api/status/{task_id}

# Артефакты
GET /api/artifacts/{task_id}
```

## 🎨 Роли агентов

### 1. Orchestrator (Оркестратор)
- Декомпозиция задачи
- Маршрутизация между агентами
- Контроль итераций (макс. 3)
- Принятие финальных решений

### 2. Product Analyst (Аналитик)
- Формализация требований
- Создание User Stories
- Определение edge-кейсов
- Критерии приёмки

**Выход:** `requirements.md`

### 3. System Architect (Архитектор)
- Выбор технологического стека
- Проектирование структуры
- Определение API контрактов
- Схема данных

**Выход:** `architecture.md`

### 4. Lead Engineer (Разработчик)
- Реализация кода по спецификациям
- Следование SOLID/DRY/KISS
- Типизация и документирование
- Базовые unit-тесты

**Выход:** Исходный код + тесты

### 5. QA Engineer (QA)
- Написание тестов (TDD)
- Unit, integration, e2e тесты
- Отчёт о покрытии
- Валидация требований

**Выход:** Тесты + отчёт

### 6. Code Reviewer (Ревьюер)
- Статический анализ
- Security audit (OWASP)
- Проверка линтеров
- Оценка читаемости

**Выход:** Отчёт о ревью

### 7. DevOps Engineer
- Dockerfile, docker-compose
- CI/CD конфигурация
- .env файлы
- Автоматизация доставки

**Выход:** Docker-образ + CI/CD

## 🔄 Цикл обратной связи

1. **QA обнаруживает ошибки** → код возвращается Разработчику
2. **Ревьюер находит замечания** → код возвращается Разработчику
3. **Лимит итераций:** 3 цикла
4. **Превышение лимита** → эскалация Оркестратору

## 📊 Мониторинг

Веб-интерфейс показывает:
- Статус каждого агента (idle/working/done/error)
- Текущую фазу выполнения
- Живой журнал сообщений
- Сгенерированные артефакты
- Историю итераций

## 🔧 Технологии

- **Backend:** Python 3.10+, FastAPI, asyncio
- **LLM:** Ollama (qwen2.5-coder:7b/14b)
- **Frontend:** React, TypeScript, Tailwind CSS
- **Хранение:** Локальная файловая система
- **Изоляция:** Docker (опционально)

## 🎯 Критерии качества

- ✅ Код проходит линтеры (flake8, pylint)
- ✅ Unit-тесты с покрытием ≥ 80%
- ✅ Security scan без блокирующих уязвимостей
- ✅ Документация (requirements.md, architecture.md)
- ✅ Docker-образ собирается успешно
- ✅ CI/CD пайплайн работает

## 🚧 Ограничения

- **Лимит итераций:** 3 цикла исправлений
- **Токеновый бюджет:** настраивается (по умолчанию 50k токенов)
- **Таймаут:** 10 минут на задачу
- **Температура:** 0.1-0.3 для детерминированности

## 🔒 Безопасность

- Агенты работают в изолированной директории
- Нет доступа к чувствительным данным
- Код выполняется в sandbox (опционально Docker)
- Локальная LLM — данные не покидают машину
